# 🌌 Interaktivne Simulacije Fizičkih Zakona

Dobrodošli u projekat **Interaktivnih simulacija fizičkih zakona**! Ovaj repozitorijum sadrži zbirku veb-baziranih simulacija koje omogućavaju vizuelizaciju i eksperimentisanje sa osnovnim konceptima fizike u realnom vremenu.

Cilj projekta je da kompleksne fizičke zakone učini intuitivnim i lakim za razumevanje kroz interaktivni vizuelni prikaz, direktno u veb pregledaču.

## 🚀 Tehnologije

Projekat je izgrađen isključivo pomoću "Vanilla" veb tehnologija, bez potrebe za spoljnim bibliotekama ili instalacijom:

*   **HTML5** (uključujući `<canvas>` element za renderovanje animacija)
*   **CSS3** (za moderan, responzivan i prilagodljiv korisnički interfejs)
*   **JavaScript (ES6+)** (za matematičke proračune, fiziku čestica i logiku simulacije)

## ⚙️ Kako pokrenuti projekat lokalno

Pošto projekat koristi čist klijentski kod (HTML/CSS/JS), pokretanje je izuzetno jednostavno:

1.  **Klonirajte repozitorijum:**
    ```bash
    git clone https://github.com
    ```
2.  **Pozicionirajte se u direktorijum:**
    ```bash
    cd ime-repozitorijuma
    ```
3.  **Otvorite u pregledaču:**
    Jednostavno dvokliknite na `index.html` fajl ili pokrenite lokalni server (npr. *Live Server* ekstenziju u VS Code-u).

## 🛠️ Kako koristiti simulacije

Svaka simulacija dolazi sa kontrolnom tablom gde možete:
1.  **Menjati parametre** u realnom vremenu (masa, gravitacija, trenje, početna brzina) pomoću slajdera (*sliders*).
2.  **Pauzirati i resetovati** simulaciju radi detaljnije analize.
3.  **Pratiti grafikone** i numeričke vrednosti koje se menjaju u toku same animacije.
